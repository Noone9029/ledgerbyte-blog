# LedgerByte Insights editor guide

## Create an article

1. Open `/studio`, sign in, and choose **Articles → Create**.
2. Write the title and select **Generate** beside the URL slug. Do not change a
   published slug without an approved redirect.
3. Add the summary, Finance or Technology pillar, topics, author, and optional
   qualified reviewer.
4. Upload a wide hero image. Add useful alternative text, a caption when it
   adds context, and a credit when required.
5. Write with paragraph, Heading 2, and Heading 3 blocks. Use lists for steps,
   tables for real comparisons, callouts for important context, and code blocks
   only when readers need to copy code.
6. Add current primary sources for finance, payroll, tax, compliance, or
   regulatory claims. Never invent a credential, result, client, date, or rule.
7. Complete the related service CTA and Search and social fields.
8. Open **Presentation** to preview desktop and mobile layouts. Fix all red
   validation errors and review yellow editorial warnings.
9. Publish. The public page updates automatically through the signed webhook.

## Image standards

- Prefer original LedgerByte artwork or properly licensed editorial imagery.
- Never upload customer records, private exports, invoices, payroll data, or
  screenshots containing personal information.
- Use a descriptive filename and alternative text; do not stuff keywords.
- Crop with the hotspot tool rather than uploading duplicate files.

## Editorial checklist

- The opening answers the article’s main question directly.
- Headings describe what follows and can stand alone in search results.
- Claims are specific, attributable, and current.
- Links point to the closest useful LedgerByte service—not every service.
- Publication and modification dates reflect real editorial events.
- Global articles avoid implying UAE/KSA applicability; regional articles state
  their jurisdiction and source official authorities.
